# 가격표 이미지 폰트 스펙 (A안 / B안)

가격표 생성기가 실제로 그리는 값 기준입니다. 모든 수치는 출력 이미지의 픽셀(px) 단위입니다.

- 정리일: 2026-10-13

## 공통

| 항목 | 값 |
|---|---|
| 서체 | Pretendard (모든 텍스트 동일) |
| 사용 굵기 | 400 Regular, 600 SemiBold, 700 Bold, 800 ExtraBold |
| 기본 글자색 | `#474F57` |
| 배경색 | `#FFFFFF` |
| 썸네일 배경색 | `#F5F5F5` |
| 줄바꿈 | 엑셀 셀 안의 줄바꿈 그대로 반영, 텍스트 영역 최대 폭을 넘으면 자동 줄바꿈 |

### 할인가 글자색 (할인율별)

할인 상품일 때 할인가 숫자와 그 앞의 ₩ 기호에 적용됩니다. A안, B안 동일합니다.

| 할인율 | 색상 |
|---|---|
| 20% 이상 | `#BE1D2C` |
| 15% 이상 20% 미만 | `#E83817` |
| 10% 이상 15% 미만 | `#E5006C` |
| 10% 미만 | `#E91E8C` |

## 참고: 커스텀 사이즈

커스텀은 A안을 그대로 그린 뒤 비율을 유지한 채 축소한 이미지입니다. 서체, 굵기, 색상은 A안과 같고 크기만 아래 배율로 줄어듭니다.

- 배율 = (가로 ÷ 1984) 와 (세로 ÷ 803) 중 작은 값
- 기본값 2055 × 673px 의 배율은 약 0.838 이고, 좌우에 흰 여백이 약 196px 씩 생깁니다.

| 요소 | A안 | 2055 × 673px 일 때 |
|---|---|---|
| 상품명 | 70px | 약 58.7px |
| 서브타이틀 | 48px | 약 40.2px |
| 상품설명 | 48px (행간 58px) | 약 40.2px (행간 약 48.6px) |
| 가격 숫자 | 100.8px | 약 84.5px |
| ₩ 기호 | 32px | 약 26.8px |
| 배지 (width × height) | 220 × 190px | 약 184 × 159px |
